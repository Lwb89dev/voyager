# Native rewrite feature parity matrix

Audit date: 2026-10-27. This matrix describes audited source, not completion claims.

## Baselines and status vocabulary

- Voyager baseline: `04a5d669514b39cf5bce943bd51cafe3cad415f6` (`v0.2.4`, Flutter 0.2.4+6).
- Roadstr production baseline: `043abd770ce6d3e6ac83be08dd727782b44ccc6d` (`v1.2.3`).
- Roadstr `main` at audit: `9cb5352905358be586bdfa701efc296469f63a47`; its only change after the tag is F-Droid metadata, so the production code baseline remains 1.2.3.
- Legacy Voyager verification: 136 Flutter tests passed on the baseline.

`INTEGRATE` means the real Roadstr implementation exists and must be consumed through the shared module, not rewritten. `PORT` means Voyager needs its own Kotlin implementation. `BRIDGE` means a temporary, isolated compatibility reader is permitted only for legacy migration. Nothing is marked complete until its Voyager runtime path and tests pass. Device-only evidence remains separately unverified.

## Verification boundaries

- 2026-10-29 native check: 75 Voyager JVM tests passed and all debug APK variants assembled. Coverage includes podcast cache/resume and a real Hive 2.2.3 encrypted migration fixture, corruption/wrong-key rejection, unsupported-data reporting, retry, verification and idempotence. This is compile/JVM evidence only, not a device-parity claim.
- 2026-10-28 Galaxy S24 (Android 16/API 36, arm64) ADB checks passed: install and cold start, MapLibre with real GPS, night scrim, live Open-Meteo/Nominatim, MediaStore albums/art, real Media3 playback and queue transitions, media play-pause/next keys, settings persistence across reinstall/restart, idle phone capability, and unavailable-model voice behavior without microphone escalation. A default-text contrast defect found during these checks was fixed in `VoyagerTheme` and retested on device.
- 2026-10-29 Galaxy S24 fresh-install ADB check passed through Roadstr onboarding, disclaimer and dashboard startup. Voyager chrome is hidden until onboarding completes because it otherwise covered the required continuation actions. The following podcast device check could not be performed because ADB disconnected before the Podcast screen opened.
- 2026-10-29 Pixel 10 ADB check with no legacy Hive file reached the normal fresh-install onboarding without a migration error and wrote the no-data completion marker. This does not validate Keystore decryption or a signed legacy upgrade.
- 2026-10-29 Pixel 10 screenshot checks passed in portrait, landscape and Roadstr settings: a shared 104 dp inset keeps Roadstr actions and labels above Voyager chrome. The Roadstr brightness slider stops at 75%; before/after evidence is in `docs/screenshots/native-chrome-*.png` and `native-brightness-75.png`.
- Still unverified on device: podcast offline/resume behavior, screen-off guidance, live calls, downloaded-model speech, sustained map performance, battery behavior, physical Bluetooth/head-unit controls, MeshCore radio, and signed migration from an installed legacy Voyager APK. Roadstr upstream device claims are not Voyager device evidence.
- Public Transitous production-load coordination, real bunker/NWC flows, compatible-format public publishing, native-speaker review, and offline-STT phone validation remain upstream limitations as well.
- No fake service, placeholder success path, or documentation-only row may be counted as complete.
